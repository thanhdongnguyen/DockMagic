Use case: stylized-concept.
Asset type: one original collectible streak achievement badge for DockMagic, a macOS productivity app. This is badge ART ONLY, not a UI screen.
Target dimensions: square 1024 x 1024 pixels, genuine transparent PNG background; alpha zero everywhere outside the hexagonal badge silhouette.

Keep central symbol recognizable at 48px, not just at large size. Do not reproduce any exact badge artwork from the reference; invent the central symbol described. Transparent background means actual alpha, NOT a checkerboard painted into the image.
ALPHA DELIVERY: Actual RGBA transparency like the isolated Builder reference; never paint a checkerboard. If the style screenshot shows page backgrounds, ignore them entirely.
Input images: Image 1 is the user's style reference (ignore the UI); Image 2 is the Builder family anchor. Match Image 2's precise drawing style, hex shape, bold outline, scale and alpha transparency, while replacing the central object and following the rank/palette directive below. This is one new sibling, not a collage.
Badge-specific directive: Entry achievement. Same periwinkle and cobalt blue rim, navy inner field. Central icon: one large warm golden four-point spark with a bold lightning-shaped ivory inner facet; one small secondary gold sparkle at its upper right, fully inside the frame. It should read as a spark of creative energy, not a compass, flame or star rating. No rank star at bottom.

## Background correction for the nine sibling assets

All nine initial sibling exports also contained a baked checkerboard. Each received one independent built-in ImageGen background-extraction edit using its own initial image as the edit target (not Builder). Exact prompt:

```text
Use case: background-extraction. Edit the attached badge only to REMOVE THE ENTIRE GRAY CHECKERBOARD BACKGROUND. Preserve the complete illustrated hexagonal medal, the central object, stars, exact geometry, colors and composition. Output one square PNG with GENUINELY TRANSPARENT alpha=0 pixels outside the hexagon. Do not draw a checkerboard or simulate transparency. No white background, no new decorations, no captions. Crisp antialiased cutout edge. Do not change the badge artwork.
```

## Short background retry

The first extraction was still opaque for Spark, Loop, Flow, Navigator, Architect,
Keystone and Continuum. A second independent extraction call for each used its
first extraction output as the target and this shorter prompt:

```text
Remove the background from the attached badge. Deliver a transparent-background PNG cutout of the hexagon, with no checkerboard. Keep the artwork inside the hexagon unchanged.
```

## Authorized local finishing

After two extraction attempts still left Loop, Navigator, Keystone and Continuum
opaque, the user explicitly approved local background removal. Their initial
ImageGen artwork was retained. `remove-checker-background.swift` removed only the
border-connected neutral checkerboard; all retained RGBA pixels were unchanged.
This finishing step is not ImageGen CLI/API fallback, and used no API key or model.
